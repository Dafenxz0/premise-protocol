# PREMiSE backlog outside the evidence-first scope

These items may be valuable for a production product, but they do not belong in the proof of the core primitive. They must not be presented as implemented by premise/1.

- Production KMS/HSM integration and key rotation policy.
- OIDC/SCIM/enterprise identity federation.
- Additional cloud services, hosted control planes, dashboards, or billing.
- Embedding, vector databases, ranking, or a new retrieval engine.
- A universal memory store or universal truth authority.
- More large connectors before the current GitHub/filesystem/PostgreSQL worlds have independent evidence.
- A real GitHub mutating adapter in the default benchmark path.
- Provider-specific prompt tuning that is not frozen and disclosed.
- Claims about general model intelligence, agent autonomy, or an SLA.
- Automatic GA declaration without an independent holdout, real provider cost data, immutable external rollback images, and operational review.

Every backlog item needs a measurable user outcome and an owner before it returns to the active scope.
