# PREMiSE stale-memory demo

Open `index.html` directly in a browser. No server, package install, API key,
database, or dashboard is required.

Press **Simular el cambio A → B** to see the same task without a validity gate
and with PREMiSE. The source changes from A to B while the agent is working.
The second path detects the version mismatch, reads again, and uses the new
fact. The demo is illustrative; the benchmark artifacts contain the measured
control results.
