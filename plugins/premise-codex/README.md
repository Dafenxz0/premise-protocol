# PREMiSE Codex plugin

This source plugin packages the PREMiSE agent workflow and its optional local
MCP entrypoint. The workflow teaches evidence identity, freshness checks,
fail-closed decisions, and guarded side effects. The runtime remains the
authority for validation and action enforcement.

The plugin is a repository artifact while PREMiSE is a candidate release. It
does not claim that the registry package or an external connector is
available. See docs/adoption-reality-wave.md for the evidence boundary.
